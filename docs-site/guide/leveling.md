# Leveling Checklist

The Leveling page tracks permanent campaign rewards so you can see what a character has already claimed and what is still missing.

## Character Modes

You can use the checklist in two ways:

- **OAuth connected** - pick a character from your account and show current XP/level details when available.
- **Manual** - enter a character name and track progress locally without account access.

Progress is stored per character name.

## Memory-Only Live Zone Follow

The checklist itself does not need memory reading. Manual progress, OAuth character selection, filters, and reward completion all work without reading the PoE2 process.

The **Auto zone** control is memory-only. It appears only after memory reading is enabled because it depends on Live Tracking's current area detection.

## Filters

Use the filters to narrow the checklist by:

- Act
- Reward type
- Completion state
- Search text

Quick filters help jump to common reward groups.

## Live Zone Follow

When Live Tracking is running, the checklist can follow your current zone and highlight relevant rewards for that area. This is useful while leveling because the page can stay focused on the zone you are actually in.

If memory reading is disabled, the checklist remains usable but current-zone follow is hidden.

## Completing Rewards

Check off rewards as you finish them. For rewards with choices, select the choice you took so the checklist remains useful when you review the character later.
