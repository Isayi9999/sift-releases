# Skill Tree

The Skill Tree page is an inspection tool for the bundled PoE2 passive tree data.

## What It Shows

Use the tree to:

- Load and fit the full passive tree.
- Search nodes and stats.
- Focus class starting areas.
- Toggle small, ascendancy, mastery, jewel, and anointable nodes.
- Inspect node stats and anoint recipes where available.

## Character Equipment

If OAuth character access is connected, the page can load characters and show equipped gear beside the tree. This is useful when checking whether a passive, anointment, or item setup matches the character you are reviewing.

## Notes

The Skill Tree page is for inspection. It does not currently edit in-game trees or export build plans.
