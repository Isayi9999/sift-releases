# Anointment Checker

The Anointment Checker helps you search PoE2 anointments and compare their Liquid Emotion cost.

## What It Uses

Sift ships an anointment dataset and combines it with current market prices for Liquid Emotions where available. The current dataset targets PoE2 0.5 anointments.

## How To Use It

1. Open **Crafting > Anointments**.
2. Search for a passive, stat, or keyword.
3. Sort or scan the results by cost.
4. Review the required Liquid Emotions and estimated total value.

## Reading Results

Each result shows the passive name, relevant stats, required emotions, and estimated cost. Treat the cost as a market estimate because Liquid Emotion prices can move quickly.
